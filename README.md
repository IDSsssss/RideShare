# Система поиска попутчиков (RideShare)

## Описание проекта

Данный проект представляет собой систему поиска попутчиков, разработанную на языке **Java**.

Система позволяет пользователям:
- создавать поездки
- искать поездки
- бронировать места
- просматривать информацию о водителях и пассажирах

---

## Функциональные возможности

### Пользователь

Пользователь может:

- Зарегистрироваться
- Войти в систему
- Просмотреть список поездок
- Найти поездку по параметрам
- Забронировать место

---

### Водитель

Водитель может:

- Создавать поездки
- Редактировать поездки
- Удалять поездки
- Просматривать пассажиров

---

### Поиск поездок

Система позволяет искать поездки по:

- Городу отправления
- Городу прибытия
- Дате поездки
- Количеству мест
